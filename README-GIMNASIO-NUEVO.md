# Crear la app de un gimnasio nuevo

1. Copia este proyecto con otro nombre.
2. Cambia solo `club.config.js`: nombre, logo, colores, palabras y la firma "Powered by Aetherium".
3. Pon el logo del gimnasio en `img/` y el icono en `icon-192.png` / `icon-512.png` / `manifest.webmanifest`.
4. Los premios y los puntos por visita los define el gimnasio en su panel (Entrada del club).
5. Publica en Vercel con su propio proyecto (y, cuando exista, su propia base de datos).

Pendiente para producto real: base de datos central por gimnasio. Hoy los datos viven en el celular de cada socio.
